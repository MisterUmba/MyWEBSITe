Mine Sweeper

This is the classic game where you attempt to clear the board of all booms

Controls

Left-Click: Reveals current tile. If it's a boom game over.

left-clicking on a already reveal tile while reveal the tiles around it

Right-Click: Places a flag on the current tile. If the current tile already has a flag, the it is removed.
